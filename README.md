# IF3170_G13_adayinfishyslife

Aplikasi pencarian dan visualisasi konfigurasi muatan truk menggunakan Hill Climbing, Simulated Annealing, dan Genetic Algorithm.

## Setup dan Menjalankan Program

```bash
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```
