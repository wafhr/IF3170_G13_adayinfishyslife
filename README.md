# IF3170_G13_adayinfishyslife

## Mode multi-truk

Atur **Jumlah truk** pada sidebar sebelum menjalankan eksperimen. Semua truk memakai dimensi dan kapasitas yang sama dari `config/problem.json`. Pencarian mengoptimalkan total objective armada; setiap paket hanya dapat ditugaskan ke satu truk dan kapasitas serta aturan penumpukan diperiksa per truk. Hasil JSON menyimpan jumlah truk dan assignment paket (`truck_index`), sedangkan grafik menyediakan pemilih truk untuk melihat tata letak masing-masing.
